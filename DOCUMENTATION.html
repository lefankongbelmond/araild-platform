🚀 Démarrage rapide

En 5 minutes, votre plateforme tourne en local

1

Configurer le backend

cd backend cp .env.example .env # puis éditez les variables npm install npx prisma db push # crée les tables npm run db:seed # données initiales npm run dev # → http://localhost:4000
2

Configurer le frontend

cd frontend echo "NEXT_PUBLIC_API_URL=http://localhost:4000/api" > .env.local npm install npm run dev # → http://localhost:3000
3

Accéder à l'admin

URL : http://localhost:3000/admin/login

Email : admin@araild.com · MDP : Admin@ARAILD2024!

⚠️ Changez ce mot de passe immédiatement en production !

4

Production avec Docker

cp .env.example .env # remplir TOUTES les variables docker-compose up -d # lance les 5 services docker exec araild_api npx prisma migrate deploy docker exec araild_api npm run db:seed
