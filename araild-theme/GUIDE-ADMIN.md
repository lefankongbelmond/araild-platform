# Guide d'administration — Thème ARAILD

Ce guide explique pas à pas comment gérer le contenu du site sans toucher au code.
Toutes les modifications se font depuis le **tableau de bord WordPress**.

---

## 1. Changer le logo
**Apparence → Personnaliser → Identité du site → Logo**
1. Cliquez sur « Sélectionner un logo ».
2. Téléversez votre image (PNG transparent recommandé, ~240×80 px).
3. Cliquez sur « Publier ».
> Sans logo, le nom « ARAILD » s'affiche en texte stylisé.

## 2. Modifier les coordonnées
**Apparence → Personnaliser → ARAILD — Paramètres du site → Coordonnées & Contact**
- Téléphone, Email, WhatsApp (chiffres uniquement, ex. `237650708330`), Adresse, Antennes, Horaires.
- Ces informations alimentent l'en-tête, le pied de page et la page Contact.

## 3. Modifier les couleurs
**Apparence → Personnaliser → ARAILD — Paramètres du site → Couleurs de la marque**
- Choisissez la **couleur primaire** et la **couleur accent** via les sélecteurs.
- L'aperçu se met à jour ; cliquez sur « Publier ».

## 4. Modifier le contenu de l'accueil (bloc par bloc)
**Apparence → Personnaliser → ARAILD — Paramètres du site**
- **Accueil → Hero** : titre, slogan, description, image de fond, 2 boutons, 4 statistiques.
- **Accueil → Axes / Valeurs / Impact / Projets vedette / Partenaires / Équipe** : chaque section possède un **titre**, une **intro**, et une case **« Afficher cette section »** pour la masquer.
- **Footer & CTA** : description du pied de page et bannière d'appel à l'action finale.
- Zone libre : modifiez la page **Accueil** (Pages → Accueil) pour ajouter des blocs Gutenberg sous les sections.

## 5. Ajouter / modifier un membre de l'équipe
**Membres → Ajouter** : Titre = nom de la personne. Champ **Rôle / Fonction**, **Ordre d'affichage**. Image mise en avant = photo (sinon initiales automatiques).

## 6. Ajouter / modifier un partenaire
**Partenaires → Ajouter** : Titre = nom. Renseignez **Site web**, **Niveau** (`strategique`, `technique` ou `financier`) et l'**Image mise en avant** = logo.

## 7. Ajouter / modifier un projet
**Projets → Ajouter** : Titre, contenu/extrait, image mise en avant. Champs : **Statut** (En cours / Terminé / À venir), **Axe associé**, **Avancement (%)**, **Lieu**. Les filtres de la page Projets se génèrent automatiquement par axe.

## 8. Ajouter / modifier un document
**Documents → Ajouter** : Titre, extrait (description), **Catégorie**, **Fichier (médiathèque)** via le bouton « Choisir un média ». Les documents sont regroupés par catégorie avec un bouton de téléchargement.

## 9. Ajouter / modifier un résultat / indicateur
**Résultats → Ajouter** : Titre = chiffre + libellé (ex. « 222 consultations gratuites »). Champs : **Chiffre**, **Domaine** (Santé, Environnement, Gouvernance…), **Icône (emoji)**. Les chiffres s'animent automatiquement.

## 10. Ajouter un article d'actualité
**Articles → Ajouter** : titre, contenu, image mise en avant, **catégorie**. L'article apparaît sur la page **Actualités**.

## 11. Modifier les axes d'intervention
**Axes → (sélectionner un axe)** : Titre, contenu détaillé, et champs **Numéro de l'axe**, **Icône**, **Résumé court**, **Lien page détail**. Les pages Axe 1 à 4 affichent automatiquement le contenu de l'axe correspondant à son numéro.

## 12. Modifier les valeurs
**Valeurs → (sélectionner)** : Titre, description (contenu), **Icône (emoji)**, **Couleur** (ex. `#6a1b9a`).

## 13. Gérer le menu de navigation
**Apparence → Menus**
1. Créez ou modifiez le menu.
2. Ajoutez pages / liens, glissez pour réordonner (un sous-élément crée un menu déroulant).
3. Assignez l'emplacement **« Menu Principal »** (et éventuellement « Menu Footer »).

## 14. Ajouter des photos (médiathèque)
**Médias → Ajouter** pour téléverser. Toutes les images mises en avant et les uploads (logos, documents) passent par la médiathèque.

---

### Astuces
- La FAQ se gère via **FAQ → Ajouter** (champ Réponse ou contenu de l'article).
- Pour masquer une section de l'accueil : décochez « Afficher cette section » dans le Personnalisateur.
- Pensez à cliquer **Publier / Mettre à jour** après chaque modification.
