# MX-CONNECT — mise à jour du 02/11/2026 (`mxconnect-maj-20261102.zip`)

Version : **2026.11.02**.

ZIP **cumulatif** : il contient les Lots 3 à 8 et ce Lot 9. Il suffit d'installer celui-ci.

## ⚠ À lire avant d'installer : TOGETHER

Sur la liste des mutuelles, **TOGETHER apparaît « Suspendue »**.

Jusqu'ici, « Suspendre » ne faisait rien : l'espace restait ouvert. **Avec cette mise à jour, la suspension ferme réellement l'espace** :
- back-office ;
- portail des prestataires ;
- espace et API des membres.

Si TOGETHER ne doit pas être fermée, **réactivez-la juste après l'installation** : Mutuelles → TOGETHER → « Réactiver la mutuelle ». Ses données ne sont jamais touchées.

## 1. Le besoin

- L'espace super-admin n'était pas lisible : menu en haut qui débordait, rubriques coupées, aucun menu sur téléphone.
- On ne pouvait pas **réactiver** une mutuelle suspendue, et la suspension n'avait aucun effet.
- Seuls 2 pays existaient, la Côte d'Ivoire enregistrée en XAF au lieu de XOF.
- Chaque mutuelle exigeait une **base créée à la main dans le panneau LWS**.

## 2. Ce qui change

### 2.1 Création des mutuelles sans le panneau LWS

LWS ne propose aucune API pour créer des bases, et son nombre de bases est limité selon l'offre. L'astuce retenue, comme vous l'avez choisi :

- **Une nouvelle mutuelle est créée en 1 à 2 secondes, sans rien faire dans le panneau.**
- Ses tables sont créées dans la base centrale, sous un **préfixe qui lui est propre** : `mut05_members`, `mut05_subscriptions`…
- Le logiciel n'ouvre que les tables de la mutuelle connectée : chaque mutuelle ne voit que ses données.
- Plus de limite liée au nombre de bases de votre offre LWS.
- Sont créés automatiquement :
  - le sous-domaine ;
  - 52 tables ;
  - les 8 rôles ;
  - le plan comptable SYSCOHADA ;
  - le premier administrateur. Son mot de passe provisoire s'affiche une fois.
- **Mutueltest et TOGETHER ne bougent pas** : elles gardent leur base actuelle.
- **Option avancée** (formulaire de création) : utiliser une base déjà créée dans le panneau, comme avant.
- **Sauvegardes** : la sauvegarde d'une mutuelle à préfixe ne contient que **ses** tables. La sauvegarde centrale contient tout.
- **Isolation** :
  - les données sont séparées par le logiciel : tables distinctes, aucune requête ne peut viser une autre mutuelle ;
  - sur LWS, toutes les bases utilisent de toute façon le même utilisateur MySQL ;
  - le principe « une base par mutuelle » reste possible sur un VPS (mode `auto`) ou avec l'option avancée.

### 2.2 Espace super-admin refait

- **Barre latérale** par thème :
  - Mutuelles ;
  - Commercial ;
  - Réseau social ;
  - Configuration.
- **Menu ☰ sur téléphone.**
- Chaque rôle ne voit que ses rubriques :
  - super administrateur : tout ;
  - administrateur sécurité : mutuelles, consolidation, configuration ;
  - modérateur : réseau social.
- **Mutuelles** :
  - compteurs Total / Agréées / En attente / Suspendues ;
  - recherche par nom, sous-domaine ou ville ; filtres par statut et par pays ;
  - pour chaque mutuelle : pays, devise, sous-domaine et mode de stockage.
- **Fiche d'une mutuelle** (nouvelle) :
  - identité ;
  - lien « Ouvrir son espace » ;
  - stockage ;
  - liste de ses administrateurs : double authentification, dernière connexion ;
  - historique des agréments, suspensions et réactivations : qui, quand, motif.
- **Rétablir l'accès d'un administrateur** de mutuelle (mot de passe oublié, téléphone perdu) :
  - un nouveau mot de passe provisoire s'affiche une fois ;
  - la double authentification est à reconfigurer.
- **Création** :
  - le sous-domaine est proposé à partir du nom ;
  - la devise et la langue se remplissent selon le pays.
- **Feuille de style compilée** (`css/mx-network.css`) au lieu du Tailwind CDN : plus rapide, sans service extérieur.
- Toutes les anciennes pages (Facturation, Santé, PRA, Modération…) profitent de la nouvelle mise en page. Leurs champs ont maintenant une bordure, et leurs tableaux défilent sur téléphone.

### 2.3 Activer, suspendre, réactiver

- **Agréer** : une mutuelle en attente.
- **Suspendre** : une mutuelle en attente ou agréée. **Motif obligatoire**, gardé dans l'historique.
  - L'espace affiche aussitôt « **Espace suspendu** » : back-office, portail prestataire, espace et API des membres, vérification des cartes.
  - Les données sont conservées.
- **Réactiver** : rouvre tout. La mutuelle redevient « agréée » si elle l'était, sinon « en attente ».

### 2.4 Pays

- **Liste de référence** : les **54 pays d'Afrique**, plus France, Belgique, Suisse, Canada, Haïti et États-Unis.
  - Chaque pays vient avec sa devise officielle, son indicatif et sa langue d'interface (français ou anglais).
  - On coche, on ajoute ; « Tout cocher » existe par région.
  - Les devises manquantes sont créées (ex. roupie des Seychelles).
  - Un pays déjà présent n'est jamais modifié.
- **Modifier** un pays : devise, langue, indicatif, paiement mobile.
- **Activer / désactiver** un pays : un pays inactif n'est plus proposé à la création, sans effet sur les mutuelles existantes.
- Un pays dont la devise diffère de la référence est signalé. Exemple : **Côte d'Ivoire enregistrée en XAF, la référence est XOF**. À corriger dans « Modifier » si aucune mutuelle ivoirienne n'en dépend.

## 3. Installer

1. **Sauvegarde** : base centrale, bases des mutuelles, dossier `htdocs/mconnect`.
2. Extraire le ZIP **directement dans `htdocs/mconnect`**, en remplaçant les fichiers.
   - Si un sous-dossier `mxconnect-maj-20261102/` est créé, déplacer son contenu.
   - Ne pas toucher au `.env`, ni à `vendor/`, ni à `storage/`.
3. Vérifier que le `.env` contient bien **`TENANT_DB_MODE=manual`** (déjà le cas sur LWS). `/_installation` l'affiche à la ligne « Création des mutuelles ».
4. Ouvrir https://m.araild.com une fois : les caches sont purgés. **Aucune modification de base** dans ce lot.
5. **Réactiver TOGETHER** si elle doit rester ouverte (voir l'avertissement en tête).

## 4. Vérifier (10 minutes)

- [ ] `mxconnect/VERSION` contient `2026.11.02`.
- [ ] https://m.araild.com/reseau/mutuelles : barre latérale, compteurs, liste. Sur téléphone, le menu ☰ s'ouvre.
- [ ] Configuration → Pays : ajouter 2 ou 3 pays depuis la liste.
- [ ] Mutuelles → « Nouvelle mutuelle » : nom, pays, e-mail de l'administrateur, **sans base**. La fiche s'ouvre, « Tables préfixées », avec le mot de passe provisoire.
  - ⚠ Sur LWS, le **sous-domaine** et son **SSL** se créent toujours dans le panneau : un sous-domaine pointant vers `htdocs/mconnect`.
  - Seule la base n'est plus nécessaire.
- [ ] Se connecter à ce nouvel espace avec le mot de passe provisoire.
- [ ] Fiche → « Suspendre » avec un motif : l'espace affiche « Espace suspendu ». « Réactiver » : il se rouvre.

## 6. Non inclus

  - Piste pour plus tard : un sous-domaine « joker » `*.m.araild.com` avec certificat joker. Il rendrait aussi cette étape automatique, si votre offre LWS le permet.
- **Déplacer** mutueltest ou TOGETHER vers des tables préfixées : inutile, elles restent sur leur base.
- **Supprimer** une mutuelle depuis l'écran : volontairement absent. Suspendre suffit, et les données sont conservées.
- Les anciennes pages internes (Facturation, PRA…) gardent leur contenu : seuls la mise en page, les champs et les tableaux ont été harmonisés.
