# MX-CONNECT — mise à jour du 10/11/2026 (VERSION 2026.11.10)

Livrable : `mxconnect-maj-20261110.zip` (cumulatif : contient aussi la mise à jour 2026.11.09 de l’application Android). **Aucune recompilation de l’application n’est nécessaire.**

## 1. Ce qui change
- **En-tête de l’application** (logo, cloche, avatar, menu) : il disparaît quand on fait défiler vers le bas et réapparaît dès qu’on remonte. En haut de page, ou quand le menu ☰ est ouvert, il reste affiché. Sur la page d’un projet, les onglets restent collés en haut. Le site web n’est pas modifié.
- **Inviter un ami** :
  - **où le trouver** : Mon profil, menu ☰, menu du compte et barre latérale sur ordinateur, sous `/compte/inviter` ;
  - **comment partager** : WhatsApp, Facebook, Telegram, X, LinkedIn, SMS, e-mail, « Copier le lien », et le bouton « Partager… » du téléphone (il ouvre directement la liste des applications installées) ;
  - **ce qui est envoyé** : un message à votre nom avec le lien d’inscription ;
  - **le lien ne contient aucun identifiant** et rien n’est enregistré sur l’invitation.
- **Réglages de l’application** (super-admin) : on peut coller l’empreinte telle que copiée depuis Android Studio (« SHA-256: AB:CD:… »), le préfixe est ignoré.

## 2. La barre « m.araild.com » en haut de l’application (zone entourée en vert)
Cette barre est affichée **par Chrome**, pas par MX-CONNECT. Elle reste tant que le site n’a pas « reconnu » l’application. Pour la faire disparaître :
1. Dans Android Studio : panneau **Gradle** (à droite) → `app › Tasks › android › signingReport` (double-clic). Dans le résultat, copiez la ligne **SHA-256** de la variante que vous avez installée (`debug` si vous avez utilisé ▶ Run, `release` pour la version signée).
2. Site → **Réseau (super-admin) → Application Android → Réglages → Empreintes SHA-256** : collez la ligne → Enregistrer.
3. Vérifiez https://m.araild.com/.well-known/assetlinks.json : il doit afficher `com.araild.mxconnect` et votre empreinte.
4. **Désinstallez puis réinstallez** l’application. Chrome refait la vérification à l’installation. La barre disparaît.

Gardez les deux empreintes (debug et release, une par ligne) si vous utilisez les deux versions. Pour le Play Store, ajoutez celle de la console Play (Intégrité de l’application).

## 3. Installer
Extraire `mxconnect-maj-20261110.zip` dans `htdocs/mconnect` en remplaçant tout (y compris `index.php` et `.htaccess`), puis ouvrir https://m.araild.com. Aucune migration.

- Dans l’application : faire défiler l’accueil vers le bas → l’en-tête disparaît ; remonter un peu → il revient.
- Mon profil → **Inviter un ami** → **WhatsApp** : le message s’ouvre dans WhatsApp, prêt à envoyer.
